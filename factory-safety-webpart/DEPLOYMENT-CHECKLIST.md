# Λίστα Ελέγχου Ανάπτυξης (Deployment Checklist)

## Πριν την Ανάπτυξη

### ✅ Προετοιμασία

- [ ] Έχετε κάνει backup του τρέχοντος web part (αν υπάρχει)
- [ ] Έχετε δοκιμάσει το web part τοπικά με `gulp serve`
- [ ] Έχετε ελέγξει ότι όλα τα περιεχόμενα είναι ενημερωμένα και σωστά
- [ ] Έχετε αυξήσει το version number στο `package.json` και `package-solution.json`
- [ ] Έχετε δικαιώματα στο SharePoint App Catalog

### ✅ Build Process

- [ ] Εκτελέσατε: `gulp clean`
- [ ] Εκτελέσατε: `gulp bundle --ship`
- [ ] Εκτελέσατε: `gulp package-solution --ship`
- [ ] Βεβαιωθήκατε ότι δεν υπάρχουν build errors
- [ ] Το αρχείο `.sppkg` δημιουργήθηκε στο `sharepoint/solution/`

## Κατά την Ανάπτυξη

### ✅ SharePoint App Catalog

- [ ] Συνδεθήκατε στο SharePoint Admin Center
- [ ] Μεταβήκατε στο App Catalog (`https://[tenant].sharepoint.com/sites/apps`)
- [ ] Ανεβάσατε το αρχείο `.sppkg` στο "Apps for SharePoint"
- [ ] Κάνατε κλικ στο "Deploy" button
- [ ] Επιλέξατε "Make this solution available to all sites in the organization"
- [ ] Το status είναι "Deployed" (όχι "Failed" ή "Pending")

### ✅ Έλεγχος CDN (Προαιρετικό)

Αν χρησιμοποιείτε CDN:

- [ ] Ανεβάσατε τα αρχεία από `temp/deploy/` στο CDN
- [ ] Βεβαιωθήκατε ότι τα αρχεία είναι προσβάσιμα
- [ ] Το `cdnBasePath` στο `write-manifests.json` είναι σωστό

### ✅ Προσθήκη στη Σελίδα

- [ ] Μεταβήκατε στη σελίδα SharePoint προορισμού
- [ ] Κάνατε κλικ "Edit page"
- [ ] Προσθέσατε το web part από το "+" menu
- [ ] Βεβαιωθήκατε ότι το web part φορτώνει σωστά
- [ ] Ρυθμίσατε τις παραμέτρους του web part (αν χρειάζεται)

### ✅ Έλεγχος Περιεχομένου

## Σε Περίπτωση Προβλήματος

### 🆘 Rollback Procedure

Αν κάτι πάει στραβά:

1. **Άμεση Ενέργεια**:
   - Κρύψτε το web part από τη σελίδα (Edit > Delete web part)
   - Ή επαναφέρετε την προηγούμενη έκδοση της σελίδας

2. **Rollback στο App Catalog**:
   ```
   - Πηγαίνετε στο App Catalog
   - Βρείτε το app
   - Κάντε κλικ "..." > "Remove"
   - Ανεβάστε την προηγούμενη έκδοση του .sppkg
   ```

3. **Ειδοποίηση**:
   - Ενημερώστε το IT support
   - Τεκμηριώστε το πρόβλημα
   - Ειδοποιήστε τους χρήστες
