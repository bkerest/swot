# Standalone HTML Version - Οδηγίες Χρήσης

## Τι είναι αυτό;

Αυτό είναι μια **αυτόνομη HTML σελίδα** που μπορείτε να ανεβάσετε απευθείας στο SharePoint χωρίς να χρειάζεται να εγκαταστήσετε το SPFx web part. Είναι η **απλούστερη λύση** για γρήγορη ανάπτυξη.

## Πλεονεκτήματα

✅ **Πολύ απλή ανάπτυξη** - Μόνο ένα αρχείο HTML
✅ **Δεν χρειάζεται Node.js** ή άλλα εργαλεία
✅ **Δεν χρειάζεται build process**
✅ **Λειτουργεί αμέσως** μετά το upload
✅ **Εύκολη επεξεργασία** - Απλό HTML/CSS/JavaScript
✅ **Responsive** - Λειτουργεί σε mobile, tablet, desktop
✅ **Δυνατότητα εκτύπωσης** ενσωματωμένη

## Μειονεκτήματα

❌ Δεν ενσωματώνεται πλήρως με το SharePoint UI
❌ Δεν έχει SharePoint property pane
❌ Δεν μπορεί να χρησιμοποιηθεί ως web part σε σελίδες

## Πώς να το Ανεβάσετε στο SharePoint

### Μέθοδος 1: Document Library (Συνιστάται)

1. **Πηγαίνετε στο SharePoint site σας**

2. **Δημιουργήστε ή ανοίξτε ένα Document Library**
   - Π.χ. "Safety Documents" ή "Εγγραφα Ασφαλείας"

3. **Ανεβάστε το αρχείο**
   - Drag & drop το `factory-safety-standalone.html`
   - Ή κάντε κλικ "Upload" > "Files"

4. **Λάβετε το link**
   - Κάντε δεξί κλικ στο αρχείο > "Copy link"
   - Ή ανοίξτε το αρχείο και αντιγράψτε το URL

5. **Προσθέστε σε σελίδα SharePoint**
   - Επεξεργαστείτε μια σελίδα SharePoint
   - Προσθέστε ένα **"Embed" web part**
   - Βάλτε το URL του HTML αρχείου
   - Ή προσθέστε ένα **Link** που ανοίγει τη σελίδα σε νέο tab

### Μέθοδος 2: Wiki Page (Legacy SharePoint)

1. Πηγαίνετε στο SharePoint site

2. Site Contents > Site Pages > New > Wiki Page

3. Επεξεργαστείτε τη σελίδα

4. Insert > Embed Code > Βάλτε το περιεχόμενο του HTML

### Μέθοδος 3: Modern Page με File Viewer

1. Δημιουργήστε Modern Page

2. Προσθέστε **"File viewer" web part**

3. Επιλέξτε το uploaded HTML file

4. Publish τη σελίδα

### Μέθοδος 4: Direct Link

Απλά μοιραστείτε το direct link στο αρχείο:
```
https://your-tenant.sharepoint.com/sites/yoursite/Shared%20Documents/factory-safety-standalone.html
```

Οι χρήστες μπορούν να το ανοίξουν απευθείας στο browser.

## Πώς να το Επεξεργαστείτε

### Επεξεργασία Περιεχομένου

1. **Κατεβάστε το αρχείο** από το SharePoint (ή επεξεργαστείτε το τοπικό)

2. **Ανοίξτε με text editor**:
   - Notepad++
   - VS Code
   - Sublime Text
   - Ή ακόμα και το απλό Notepad

3. **Βρείτε την ενότητα που θέλετε να αλλάξετε**:
   - Κείμενο βρίσκεται μέσα στα `<div>`, `<p>`, `<li>` tags
   - Τίτλοι στα `<h1>`, `<h2>`, `<h3>` tags

4. **Κάντε τις αλλαγές σας**

5. **Αποθηκεύστε το αρχείο**

6. **Ανεβάστε ξανά στο SharePoint** (θα αντικαταστήσει το παλιό)

### Παραδείγματα Επεξεργασίας

#### Αλλαγή Ονόματος Εταιρείας

Βρείτε:
```html
<h2>ELVIAL SA - Εργοστάσιο Διέλασης Αλουμινίου</h2>
```

Αλλάξτε σε:
```html
<h2>ΤΟ ΟΝΟΜΑ ΣΑΣ - Περιγραφή</h2>
```

#### Αλλαγή Τηλεφώνων

Βρείτε την ενότητα contact-grid και αλλάξτε:
```html
<div class="contact-card">
    <strong>Υπεύθυνος Ασφαλείας</strong>
    <span class="number">εσωτ. 250</span>
</div>
```

#### Προσθήκη Νέου ΑΜΠ

Αντιγράψτε ένα υπάρχον `.ppe-card` div και τροποποιήστε το:
```html
<div class="ppe-card">
    <h3>🦺 Γιλέκο Ασφαλείας</h3>
    <p>Υποχρεωτικό στην αποθήκη</p>
    <ul>
        <li>Αντανακλαστικό υλικό</li>
        <li>Πιστοποίηση EN 471</li>
        <li>Πορτοκαλί ή κίτρινο χρώμα</li>
    </ul>
</div>
```

### Αλλαγή Χρωμάτων και Styling

Βρείτε την ενότητα `<style>` στην αρχή του αρχείου:

```css
/* Αλλαγή κύριου χρώματος (μπλε) */
/* Βρείτε: #0078d4 και αλλάξτε το σε δικό σας χρώμα */

header {
    background: linear-gradient(135deg, #YOUR-COLOR1 0%, #YOUR-COLOR2 100%);
}
```

## Εκτύπωση

Η σελίδα έχει ενσωματωμένη λειτουργία εκτύπωσης:

1. Κάντε κλικ στο κουμπί **"🖨️ Εκτύπωση"**
2. Ή πατήστε `Ctrl+P`
3. Επιλέξτε τον εκτυπωτή σας
4. Print!

**Σημείωση**: Στην εκτύπωση, όλα τα tabs εμφανίζονται αυτόματα.

## Αντιμετώπιση Προβλημάτων

### Η σελίδα δεν εμφανίζεται σωστά στο SharePoint

**Λύση**: Χρησιμοποιήστε το "Embed" web part αντί για "File viewer"

### Τα ελληνικά δεν φαίνονται σωστά

**Λύση**: Βεβαιωθείτε ότι το αρχείο είναι αποθηκευμένο σε **UTF-8 encoding**

Στο Notepad:
1. File > Save As
2. Encoding: UTF-8
3. Save

### Η εκτύπωση κόβει το περιεχόμενο

**Λύση**: Στις ρυθμίσεις εκτύπωσης:
- Επιλέξτε "A4" paper size
- Margins: Normal
- Scale: Shrink to fit

### Δεν λειτουργούν τα tabs

**Λύση**: Βεβαιωθείτε ότι το SharePoint δεν μπλοκάρει το JavaScript. Δοκιμάστε να ανοίξετε τη σελίδα σε νέο tab (direct link).

## Σύγκριση: Standalone vs SPFx Web Part

| Χαρακτηριστικό | Standalone HTML | SPFx Web Part |
|----------------|-----------------|---------------|
| Εύκολη ανάπτυξη | ✅ Πολύ εύκολη | ❌ Απαιτεί setup |
| Ενσωμάτωση SharePoint | ❌ Περιορισμένη | ✅ Πλήρης |
| Επεξεργασία | ✅ Πολύ εύκολη | ❌ Απαιτεί rebuild |
| Property Pane | ❌ Όχι | ✅ Ναι |
| Responsive | ✅ Ναι | ✅ Ναι |
| Εμφάνιση | ⚠️ Καλή | ✅ Άριστη |
| Συντήρηση | ✅ Εύκολη | ⚠️ Μέτρια |

## Πότε να Χρησιμοποιήσετε την Standalone Version

✅ **Χρησιμοποιήστε αν**:
- Θέλετε γρήγορη ανάπτυξη (σήμερα!)
- Δεν έχετε τεχνικές γνώσεις SPFx
- Χρειάζεστε μόνο μια απλή σελίδα πληροφοριών
- Θέλετε εύκολη επεξεργασία χωρίς build tools

❌ **ΜΗ χρησιμοποιήσετε αν**:
- Θέλετε πλήρη ενσωμάτωση με SharePoint
- Χρειάζεστε property pane για ρυθμίσεις
- Θέλετε το web part να εμφανίζεται σε πολλές σελίδες
- Έχετε χρόνο για SPFx setup
